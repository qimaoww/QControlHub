## 实际验证、发现及限制

- **全目录对照：59 个预设 × 6 种设备 / 主题 = 354 组**。修改前后表单字段、required / disabled / min / max / pattern 等约束、选项与读出的提交参数一致，切换所有分组检查横向溢出。[桌面浅](evidence/inbounds/modal-catalog-desktop-light.json)、[桌面深](evidence/inbounds/modal-catalog-desktop-dark.json)、[手机浅](evidence/inbounds/modal-catalog-mobile-light.json)、[手机深](evidence/inbounds/modal-catalog-mobile-dark.json)、[平板浅](evidence/inbounds/modal-catalog-tablet-light.json)、[平板深](evidence/inbounds/modal-catalog-tablet-dark.json)。
