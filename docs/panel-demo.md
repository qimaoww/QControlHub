# 完整面板动画示范

这是原始前端的独立演示入口，不是重新绘制的组件展示。`frontend/panel-demo.html` 加载原来的 `app.js`、所有页面模块、`app.css` 和共享动画运行时。额外界面仅为顶部的演示标识、全页面导航与数据恢复按钮。

从仓库根目录启动：

```sh
go run ./cmd/panel-demo
```

终端会输出本机地址。需要固定端口时可添加 `-port 45561`。该命令始终只监听 `127.0.0.1`，不提供公网监听选项。

预览工具可以把该端口映射为其他 `localhost` 端口。演示服务接受回环地址的 Host，保留来源检查，避免端口映射导致 403；非本地 Host、跨站请求和外部 Origin 仍会被拒绝。

## 内容

- 原来的总览、节点总览／详情、内核预设、手动配置、档案与修订历史、客户端、Sub-Store、访问限制、流量、日志、执行记录、设置和登录页面。
- 四种内核直接使用项目的完整协议目录与字段定义，以及原有方案生成、配置解析、字段合并和客户端参数生成函数。
- 示例含在线、离线、尚未安装的内核、可导入的服务、多端口配置、成功与失败任务，可使用原有控件进行操作。
- 保存、删除、切换版本、任务、模板与同步组只更新内存里的演示状态。读取配置返回演示快照；不执行安装、迁移、部署或服务管理。
- “下次操作模拟失败”使下一次保存或任务提交返回演示错误，用于人工体验错误反馈。恢复数据重新初始化当前演示实例。
- 默认已进入演示管理员会话。退出后可用用户名 `admin`、密码 `demo-panel-only` 再次登录；演示认证不验证真实凭据，不要输入真实密码。

## 隔离边界

没有数据库、没有 Agent 连接，也没有向真实后端转发请求。未实现的请求直接返回错误。安装脚本地址只返回说明并退出，不能安装软件；客户端地址使用文档保留地址，不是实际服务地址。

演示模型不等同于生产后端校验。尤其访问限制、远程同步、连接检查、服务执行和安全状态都只是 UI 的演示数据，不能用其结果判断生产服务是否正常。

此入口和 `cmd/panel-demo` 不被生产镜像的构建目标发布。动画行为跟随同一工作区的实际前端修改，不维护第二套演示动效。

按用户要求，本次没有运行测试或浏览器交互验证。启动预览服务仅用于交由用户体验。
