# 入站限制与 CN IP 数据源

在配置页选择入站按钮，点击同一排右侧的“限制”打开当前入站设置。弹窗显示节点、内核、入站标签和端口。公共配置和合并预览不提供入站限制；Mihomo 和 ss-rust 的完整源码编辑器通过旁边的入站按钮指定限制对象。旧的访问限制链接继续兼容，主导航入口已移除。

源码有未保存修改时先保存源码，再修改访问限制。限制保存沿用配置版本校验，成功后刷新源码和版本；取消关闭保留弹窗草稿。只读账号仅查看，离线节点不可提交。

## 设置与格式

系统设置 → CN IP 数据源。每个账号独立保存自己的 IPv4 和 IPv6 HTTPS 文件直链。格式自动识别：

- TXT：每行一个 IPv4/IPv6 地址或 CIDR，允许空行、`#` 注释和 UTF-8 BOM，自动规范化与去重。
- DAT：V2Ray/Xray GeoIP protobuf 数据库，仅提取 `cn`；不支持 geosite 或反向国家规则。
- SRS：sing-box 二进制规则集，版本 1–5，仅支持纯 `ip_cidr` 默认规则，不接受域名、反向、逻辑或其他混合条件。
- MMDB：MaxMind 数据库，提取 `country.iso_code=CN` 或 `country_code=CN` 的网络；兼容 chnroutes2 的精简元数据。
- 自动识别：根据内容识别以上格式，不依赖文件扩展名。

例如 chnroutes2 MMDB 直链：`https://raw.githubusercontent.com/misakaio/chnroutes2/master/chnroutes.mmdb`。GitHub 的 blob 页面是网页，不能作为文件直链。

两个地址均留空恢复各内核默认来源；仅一栏留空时，该地址族使用默认 TXT 源。双栈数据库可以在两栏填写同一地址，执行时只下载一次并按地址族分离。TXT/SRS 中所有网段都被视为大陆 IP，因此应选用 CN 专用规则集。指定的 IPv4/IPv6 地址必须包含对应地址族的网段，否则任务失败；不再提供手动格式选择。ss-rust 的 ACL/来源防火墙继续使用 IPv4 部分，域名 ACL 沿用原来源。

## 生效与隔离

更改设置不立即重启节点；下次配置校验或部署使用新来源。任务创建时保存发起账号的双栈源地址快照，之后该账号改源不改变已排队任务；数据文件在执行时下载。共享节点的借用者不继承主机所有者或其他用户的数据源。

自定义来源需要广告 `cnip-source-v1` 的新版 Agent，旧 Agent 不可执行相关任务。数据库升级到 schema 59，新增可空字段，旧设置默认仍有效。用户设置沿用账号隔离和配置修订检查。

下载限定 HTTPS 公网直链、32 MiB、30 秒；拒绝私有/保留目标，重定向重新验证并固定解析后的公网拨号地址。解压及解析数量有上限，错误不会静默改用默认源。生成的配置仍受 2 MiB 上限和内核校验约束，ss-rust 持久状态受 32 MiB 上限约束；部署失败使用原回滚流程。
