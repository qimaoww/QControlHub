# 面板动画与交互

本次为跨页面动画重构。按需求未执行测试、构建、浏览器验证或性能测量；下表是实现覆盖范围与人工体验入口，不代表已经验收。

## 统一规则

- 控件反馈 120 ms，局部内容 200 ms，页面／弹窗进入 240 ms，弹窗退出 160 ms。没有卡片逐个排队的长延迟。
- 页面保留导航外壳；页面与内部卡片只选一层入场，不叠加变换。后台轮询复用已有 DOM，普通数值刷新不播放入场。
- 弹窗只有关闭／取消、Esc 或保存成功等明确操作才关闭。点击窗口空白、遮罩、页面外部空白不关闭。移动端更多菜单和月份选择器同样不因点击外部空白收起。
- 弹窗完整退出后才释放原生模态层与焦点；快速重新打开取消旧的退出。添加节点和部署命令使用相同的原生弹窗，不再另设全局焦点锁定。
- 抽屉展开／收起支持反向打断；标签页在短退出后替换内容，连续选择以最后一次为准。
- 动效以 opacity／transform 为主；只有折叠内容的高度和现有进度条宽度改变布局。不做整屏模糊、不持续让正常在线节点闪烁，不长期为普通卡片保留合成层。
- 节点和流量卡片拖拽按帧合并指针移动；落位先统一读取尺寸，再统一写入，避免逐卡强制布局。
- 新插入元素的动画只覆盖可见区域，每批最多 12 个表面；隐藏内容、后台标签页、系统“减少动态效果”都有降级。降低动态效果不会影响关闭与保存逻辑。
- 成功通知可手动关闭，6 秒后自动收起，悬停／聚焦暂停计时；错误通知保留到明确关闭。弹窗内发生的错误显示在当前弹窗内。
- 页面通知独立于被刷新的内容区，保存完成后的刷新不会立即吞掉提示。原生弹窗遮罩使用可反向接续的颜色过渡，退出中重新打开不从全透明重播。
- 折叠和标签切换期间，由动画持有的不可交互状态会在 DOM 刷新中保留；动作结束或反向操作再恢复，避免中途可误点或结束后一直不可点击。

## 人工体验入口

| 页面／区域 | 交互覆盖 |
| --- | --- |
| 启动、登录 | 加载标志、登录表单反馈、登录卡片、会话过期清理弹窗 |
| 全局导航 | 页面切换、上下文侧栏、等待指示、失败后恢复、桌面提示、移动端更多菜单 |
| 总览 | 月份面板、流量详情窗口、月份内容更换 |
| 节点设置 | 总览／详情切换、资源／内核标签、版本抽屉、批量操作栏、卡片拖放 |
| 添加节点 | 表单、添加记录、生成命令、错误提示、查看已有部署命令、连续关闭重开 |
| 内核预设 | 节点／内核／入站／协议切换，参数步骤、高级参数、源码与历史折叠 |
| Shadowsocks Rust | 当前端口字段、全局默认值与源码面板，沿用统一控件与展开机制 |
| 实际配置 | 读取阶段、配置来源切换、编辑器与提交反馈 |
| 配置档案 | 档案／修订版本更换、源码与版本历史 |
| 客户端 | 节点筛选、参数详情、显示参数窗口、复制与保存反馈 |
| Sub-Store | 同步组切换、连接设置、新建／编辑／移除窗口、节点开关、提交反馈 |
| 访问限制 | 节点筛选、开关、未保存提示、操作确认 |
| 流量 | 筛选、添加／编辑配额、确认窗口、保存后收起、卡片排序 |
| 内核日志 | 筛选、插入日志、滚动位置保持 |
| 执行记录 | 状态筛选、执行结果折叠、重试／取消确认、任务反馈 |
| 设置与主题 | 全部表单与开关、未保存／已保存状态、版本检查、主题颜色过渡 |

建议关注快速连点、动画中反向操作、网络慢／失败、弹窗内报错、Esc、关闭后焦点、窄屏滚动、系统减少动态效果。原生下拉选择器和浏览器自身的提示窗口仍由浏览器／系统绘制。

## 代码入口

- `frontend/modules/motion.js`：进入队列、弹窗、折叠、标签页、忙碌反馈、按帧调度。
- `frontend/app.css` 的 Motion system v2：统一节奏、控件反馈、模态遮罩、移动端和减少动态效果。
- `frontend/app.js`：保留导航外壳、路由等待状态、通知、主题与会话清理。
- 各业务模块只指定打开／关闭和内容选择；共享逻辑不提交业务请求。
- `Dockerfile` 为入口和模块间相对导入使用同一版本号，避免动画运行时被加载成两个实例。
